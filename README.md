# Shyam Packers and Movers

Official website for Shyam Packers and Movers - ISO 9001:2015 Certified relocation service provider.

## Tech Stack
- **HTML5 & Vanilla TypeScript**
- **Tailwind CSS v4**
- **Vite**

## Getting Started

### Prerequisites
- Node.js (v18+)

### Development
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
